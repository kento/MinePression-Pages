# MinePression Research Notes

Human-focused research dashboard: https://kento.github.io/MinePression-Pages/

Generated publication bundle. Canonical source, generators and tests are maintained in the private research control repository; do not edit generated assets independently.

Public data covers synthetic repetitive-byte inputs, a measured bzip2 histogram pilot, revised warmed single-worker loop timing, conditional 1--10 byte full-space estimates, the exact low-20-bit census on Fugaku, and exact 1--4 byte FX700, Fugaku and B300 censuses. It also includes a clearly labeled analytical B300 projection for exhaustive 5--10 byte censuses. The 100-byte distribution discussion is an exploratory note, not a published sampling dataset.
